# Муравей Лэнгтона — веб-визуализация

Интерактивная визуализация клеточного автомата «Муравей Лэнгтона» на чистом
HTML + CSS + JavaScript (Canvas). Без сборки и зависимостей.

## Правила

- Муравей стоит на клетке поля.
- **Белая клетка** — поворот направо, клетка перекрашивается в чёрный.
- **Чёрная клетка** — поворот налево, клетка перекрашивается в белый.
- Затем муравей делает шаг вперёд на одну клетку.

Поле замкнуто в тор: выйдя за край, муравей появляется с противоположной стороны.

## Запуск

Просто откройте `index.html` в браузере (двойной клик) — всё работает локально.

## Структура

```
index.html   — разметка страницы
style.css    — оформление (тёмная тема, адаптивность)
script.js    — симуляция и отрисовка на Canvas
```

## Как это устроено

Поле хранится в `Uint8Array` (150 × 100 клеток). Каждый кадр:

1. выполняется N шагов симуляции (N — скорость);
2. изменённые клетки пишутся в `ImageData` размером с поле (1 клетка = 1 пиксель);
3. картинка масштабируется без сглаживания на видимый Canvas;
4. поверх рисуется треугольник-муравей с учётом направления.

Такой подход позволяет без тормозов прокручивать десятки тысяч шагов в секунду.

## Фазы поведения

- ~0–10 000 шагов — симметричные узоры;
- ~10 000–11 000 — хаотичное движение;
- после ~11 000 — «шоссе»: устойчивый цикл из 104 шагов.
